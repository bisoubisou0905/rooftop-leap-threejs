# 《纵跃》产品与界面方向

## 核心体验

- 玩家感受：游戏不是从菜单进入世界；世界本身就是菜单，第一次拖动角色即开始本局。
- 目标平台：竖屏手机浏览器优先，同时保持桌面试玩可用。
- 三个视觉支柱：简约而统一的三维风格、持续向上的城市空间、克制而有触感的边缘式 UI。具体材质质感不预设为塑料，以人物和场景的实机整体效果为准。
- 交互参考原则：借鉴《Crossy Road》“可玩场景即主页”的信息架构——借用的是界面分布与收放逻辑，不复制其角色、图标或美术表现。
- 明确避免：全屏开始菜单、阻挡角色和前方平台的大面板、游戏中持续占据画面的功能按钮、突然切换的背景阶段。

## 世界即主页

1. 主页始终显示真实可玩的角色、当前屋顶和前方路线。
2. 左上角是角色入口；当前可展示默认角色，未来扩展角色选择与装扮。
3. 右上角是设置入口；背景、声音和舒适性选项放在这里。
4. 底部是玩法切换栏；单人攀升、双人对战、每日挑战等模式使用同一位置扩展。
5. 画面中心不放“开始游戏”大按钮。玩家在场景中第一次按住并拖动角色，就直接进入蓄力并开始游戏。
6. 游戏开始时，顶部入口向上收起、底部玩法栏向下收起、品牌与提示淡出；不能出现一次额外点击。
7. 返回主页时重置本局，并让这些界面元素从画面边缘重新进入。

## 游戏中 UI

- 只保留进度、海拔、声音和返回主页等即时必要信息。
- 功能入口不得与拖拽区域争抢触摸事件。
- 失败结算是唯一允许短暂覆盖画面的主面板。

## 声音方向

- 音效保持短促、柔和、带少量都市电子质感；避免高频激光滑音、尖锐蜂鸣和夸张街机爆炸声。
- 拖拽使用低音量的触感提示，起跳以空气感和柔和低频为主，落地强调克制的重量感，完美落点才使用简短和声音程。
- 擦碰、落水、普通失败必须具有不同材质感；连续碰撞需要节流，不能因同一物理接触叠出刺耳峰值。
- 所有程序化音效经过统一总线、压缩与音量限制，不允许单个反馈突然明显高于其他声音。

## 未来扩展约定

- 新角色加入左上角角色入口，不新增第二套角色菜单入口。
- 双人模式和新玩法加入底部玩法栏，不在主页中央增加按钮。双人模式已实现为 18 段固定路线计时赛，并支持通过直达参数自动进入匹配。
- 设置继续位于右上角；新增背景、音效或操作辅助时在现有设置页扩展。
- 无论加入多少功能，直接拖动角色开始游戏的路径必须始终保留。

## 单人地图节奏

- 普通单路线是默认节奏，玩家始终能读出一个明确的前进方向。
- 左右双平台只作为低频选择事件出现，并在下一段重新汇合；不让路线持续分叉。
- 可落脚的路灯、信号杆等窄型城市构件属于更稀少的高手路线，通常与一个安全屋顶同时出现。
- 两种选择事件之间至少保留数个普通跳跃，避免连续选路造成视野混乱。
- 所有可落脚物体的视觉顶面、脚底判定与坠落侧撞体必须使用同一组尺寸数据。

## 双人计时赛基线

- 双人模式使用同一份确定性 18 段地图，双方的平台、分支、终点和机关位置完全一致。
- 机关暂不进入当前双人测试版；未来加入时必须反馈清晰，且推力只造成可恢复的小偏移。
- 水面从路线下方缓慢上涨。起跑后保留约 10 秒观察期，之后约每 7 秒推进一段；被追上直接淘汰。场景水面、推进倒计时与右侧位置尺必须同步表达同一个水位。
- 角色碰撞按相对速度与质量计算，并限制最大速度改变量。轻量角色质量为 1.0，重装角色质量为 1.65；默认碰撞恢复系数为 0.08，避免一次接触造成击飞。
- 右侧位置尺只表达双方赛段，不呈现精密轨迹；它应保持半透明、小面积、不中断落点观察。
- 双人原型以 WebRTC 点对点传输姿态，通过免费 PeerJS Cloud 信令自动匹配。严格 NAT 下没有免费 TURN 保证，因此连接失败必须可见且不伪装为已匹配。

## 角色轮廓

- 跃者保持窄肩、细肢和高可读脚底，是灵巧基准角色。
- 重装必须一眼呈现宽肩、厚胸腹和更粗上臂，但头与鞋仍保持清晰，不能膨胀成难以判断落点的团块。
- 重装使用低饱和青色上装、暖肤色与深蓝下装，继续沿用现有珊瑚橙作为小面积反馈色。
- 两个角色共用跳跃曲线；质量只影响角色之间和机关碰撞，避免角色选择变成强制数值最优解。

## 视觉不变量

- 深蓝、珊瑚橙、低饱和青色为主色；玻璃面板透明、边框纤细。
- UI 使用圆角但保持紧凑，不能变成厚重的卡片式仪表盘。
- 动效方向必须与空间位置一致：顶部向上退出，底部向下退出。
- 所有主页 UI 必须给角色、落点和前方道路让出主要视觉层级。
- 生成图片只用于探索构图、色彩和空间节奏，未经重新建模与风格统一不得直接贴入游戏画面。
- 最终城市、云层和高度变化优先使用 Three.js 场景内的几何、材质、雾与灯光实现，使透视和运动始终与角色、平台一致。
- 图标使用同一套可控的代码原生图形语言，不混用来源与笔触不一致的装饰素材。
